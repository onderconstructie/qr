Hoe werkt dit?

Met Scancode maak je van een link een code. Wie de code scant met een gsm, opent meteen de link.

  • Plak de link. De code verschijnt meteen.
  • Geef een titel als je wil. Die komt boven de code, op de afbeelding en in de PDF.
  • Neem de code mee. Kies Afbeelding voor een dia of een mail, of PDF om af te drukken.

Tip: scan de code eerst zelf met je gsm. Druk hem niet kleiner af dan 3 cm.
